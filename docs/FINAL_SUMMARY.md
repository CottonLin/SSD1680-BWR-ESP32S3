## 七、使用指南

### 7.1 快速开始

```bash
# 1. 切换到重构分支
git checkout refactor-20260302

# 2. 编译项目
idf.py build

# 3. 烧录运行
idf.py -p COM3 flash monitor
```

### 7.2 运行测试

```bash
# 运行所有测试
idf.py -p COM3 flash monitor

# 运行特定测试（标签过滤）
idf.py -p COM3 flash monitor --test-filter "canvas"
idf.py -p COM3 flash monitor --test-filter "text"
idf.py -p COM3 flash monitor --test-filter "epd_font"
```

### 7.3 导入字模数据

1. 打开 `components/epd_font/src/epd_font_data.c`
2. 从原 STM32 项目的 `EPD_Font.h` 复制字模数据
3. 粘贴到对应数组（已标注位置）
4. 编译运行

**示例**:
```c
const unsigned char g_font_8x16_data[95][16] = {
    /* 从原 STM32 项目的 asc2_1608 数组复制 */
    {0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 
     0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00},  // 空格
    /* ... 继续复制所有 95 个字符 */
};
```

### 7.4 使用新接口

```c
// 1. 创建画布
epd_canvas_t *canvas = epd_canvas_create(EPD_BUFFER_DUAL);

// 2. 清屏
epd_canvas_clear(canvas, EPD_COLOR_WHITE);

// 3. 绘制图形
epd_draw_line(canvas, 10, 10, 100, 100, EPD_COLOR_BLACK);
epd_draw_circle(canvas, 75, 75, 50, EPD_COLOR_BLACK, false);
epd_draw_rectangle(canvas, 10, 10, 100, 100, EPD_COLOR_BLACK, true);

// 4. 显示文本
const epd_font_t *font = epd_font_get(EPD_FONT_SIZE_8X16);
epd_show_string(canvas, 10, 10, "Hello World", font, EPD_COLOR_BLACK);

// 5. 刷新显示
epd_display(canvas);

// 6. 销毁画布
epd_canvas_destroy(&canvas);
```
