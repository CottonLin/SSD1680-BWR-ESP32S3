# 红色显示功能实现指南

## 📋 问题背景

### 初始问题
用户发现屏幕上显示的字体和几何图形都是**黑色**的，询问如何显示**红色**。

### 问题原因
1. **单缓冲区设计**：原始代码只有一个显存缓冲区 (`buffer`)，无法同时控制黑白和红色两个显示通道
2. **颜色定义缺失**：没有定义 `EPD_COLOR_RED` 颜色常量
3. **像素设置逻辑**：`epd_canvas_set_pixel()` 只支持黑/白两色，不支持红色通道

## 🎯 SSD1680 三色显示原理

### 双通道显示机制
SSD1680 墨水屏支持三色显示（黑/红/白），通过两个独立的显存通道实现：

| 颜色  | 黑白通道 (0x24) | 红色通道 (0x26) | 说明                    |
|-------|----------------|----------------|-------------------------|
| 黑色  | 0              | 1              | 只在黑白通道显示        |
| 红色  | 1              | 0              | 只在红色通道显示        |
| 白色  | 1              | 1              | 两个通道都不显示（背景）|

### 硬件特性
- **黑白通道**：命令 `0x24` (WRITE_RAM_BW)，控制像素显示黑色或白色
- **红色通道**：命令 `0x26` (WRITE_RAM_RED)，控制像素显示红色或白色
- **显示逻辑**：0 = 显示颜色，1 = 不显示（白色）

## 🔧 实现方案

### 方案选择：双缓冲区架构

**核心思路**：
- 创建两个独立的显存缓冲区：`buffer_bw`（黑白）和 `buffer_red`（红色）
- 画布结构体同时持有两个缓冲区指针
- 像素设置函数根据颜色参数写入对应的缓冲区

### 修改内容

#### 1. 头文件修改 (epd_gui.h)

**画布结构体更新**：
```c
typedef struct {
    uint8_t *buffer_bw;         // 黑白显存缓冲区指针
    uint8_t *buffer_red;        // 红色显存缓冲区指针
    uint16_t width;             // 逻辑宽度（用户坐标，296）
    uint16_t height;            // 逻辑高度（用户坐标，152）
    uint16_t internal_width;    // 内部宽度（SSD1680 X 方向，152）
    uint16_t internal_height;   // 内部高度（SSD1680 Y 方向，296）
    uint16_t width_bytes;       // 每行字节数（internal_width/8 = 19）
    uint16_t color;             // 当前颜色
} epd_canvas_t;
```

**颜色定义添加**：
```c
#define EPD_COLOR_WHITE     0xFF    // 白色
#define EPD_COLOR_BLACK     0x00    // 黑色
#define EPD_COLOR_RED       0x01    // 红色
```

**函数签名更新**：
```c

                                uint16_t width, uint16_t height);
```

#### 2. 实现文件修改 (epd_gui.c)

**像素设置函数** - 核心三色逻辑：
```c
void epd_canvas_set_pixel(epd_canvas_t *canvas, uint16_t x, uint16_t y, uint16_t color)
{
    // ... 坐标转换代码 ...
    
    if (color == EPD_COLOR_BLACK) {
        // 黑色：黑白通道=0，红色通道=1
        canvas->buffer_bw[byte_addr] &= ~bit_mask;
        if (canvas->buffer_red != NULL) {
            canvas->buffer_red[byte_addr] |= bit_mask;
        }
    } else if (color == EPD_COLOR_RED) {
        // 红色：黑白通道=1，红色通道=0
        canvas->buffer_bw[byte_addr] |= bit_mask;
        if (canvas->buffer_red != NULL) {
            canvas->buffer_red[byte_addr] &= ~bit_mask;
        }
    } else {
        // 白色：两个通道都为 1
        canvas->buffer_bw[byte_addr] |= bit_mask;
        if (canvas->buffer_red != NULL) {
            canvas->buffer_red[byte_addr] |= bit_mask;
        }
    }
}
```

**画布创建函数**：
```c
epd_canvas_t* epd_canvas_create(uint8_t *buffer_bw, uint8_t *buffer_red, 
                                uint16_t width, uint16_t height)
{
    // ... 初始化代码 ...
    
    canvas->buffer_bw = buffer_bw;
    canvas->buffer_red = buffer_red;
    
    // ... 其他初始化 ...
}
```

**清屏函数**：
```c
void epd_canvas_clear(epd_canvas_t *canvas, uint16_t color)
{
    // 清空黑白缓冲区
    memset(canvas->buffer_bw, color, EPD_BUFFER_SIZE);
    
    // 清空红色缓冲区（如果存在）
    if (canvas->buffer_red != NULL) {
        memset(canvas->buffer_red, color, EPD_BUFFER_SIZE);
    }
}
```

## 📊 遇到的问题及解决方案

### 问题 1：编译错误 - 函数声明冲突

**错误信息**：
```
error: conflicting types for 'epd_canvas_create'; 
have 'epd_canvas_t *(uint8_t *, uint8_t *, uint16_t, uint16_t)'
previous declaration of 'epd_canvas_create' with type 
'epd_canvas_t *(uint8_t *, uint16_t, uint16_t)'
```

**原因**：
- 实现了新的函数签名（双缓冲区参数）
- 但头文件中的函数声明没有同步更新

**解决方案**：
更新 `epd_gui.h` 中的函数声明：
```c
// 旧版本（单缓冲区）
epd_canvas_t* epd_canvas_create(uint8_t *buffer, uint16_t width, uint16_t height);

// 新版本（双缓冲区）
epd_canvas_t* epd_canvas_create(uint8_t *buffer_bw, uint8_t *buffer_red, 
                                uint16_t width, uint16_t height);
```

### 问题 2：示例文件未更新

**问题描述**：
- `epd_gui_example.c` 仍使用旧的单缓冲区 API
- 导致编译时出现参数不匹配警告

**解决方案**：
- 删除示例文件（用户要求）
- 或更新示例文件以使用双缓冲区 API

### 问题 3：内存管理

**潜在问题**：
- 双缓冲区需要分配两块内存（各 5624 字节）
- 需要确保正确释放，避免内存泄漏

**最佳实践**：
```c
// 分配
uint8_t *buffer_bw = (uint8_t *)malloc(EPD_BUFFER_SIZE);
uint8_t *buffer_red = (uint8_t *)malloc(EPD_BUFFER_SIZE);

// 使用
epd_canvas_t *canvas = epd_canvas_create(buffer_bw, buffer_red, 296, 152);
// ... 绘图操作 ...

// 释放（重要！）
epd_canvas_destroy(canvas);
free(buffer_bw);
free(buffer_red);
```

## 📝 使用示例

### 基础使用流程

```c
#include "epd_gui.h"
#include "ssd1680.h"

void app_main(void)
{
    epd_canvas_t *canvas;
    uint8_t *buffer_bw;
    uint8_t *buffer_red;
    const epd_font_t *font;
    
    // 1. 初始化显示屏
    epd_init();
    
    // 2. 创建双缓冲区
    buffer_bw = (uint8_t *)malloc(EPD_BUFFER_SIZE);
    buffer_red = (uint8_t *)malloc(EPD_BUFFER_SIZE);
    
    // 3. 创建画布
    canvas = epd_canvas_create(buffer_bw, buffer_red, 296, 152);
    
    // 4. 清屏（白色）
    memset(buffer_bw, 0xFF, EPD_BUFFER_SIZE);
    memset(buffer_red, 0xFF, EPD_BUFFER_SIZE);
    epd_display(buffer_bw, buffer_red);
    
    // 5. 绘制内容
    // 黑色边框
    epd_draw_rectangle(canvas, 0, 0, 295, 151, EPD_COLOR_BLACK, 0);
    
    // 红色实心圆
    epd_draw_circle(canvas, 100, 50, 30, EPD_COLOR_RED, 1);
    
    // 红色字体
    font = epd_font_get(EPD_FONT_SIZE_12X24);
    epd_show_string(canvas, 10, 10, "Hello Red!", font, EPD_COLOR_RED);
    
    // 6. 刷新显示
    epd_display(buffer_bw, buffer_red);
    
    // 7. 清理资源
    epd_canvas_destroy(canvas);
    free(buffer_bw);
    free(buffer_red);
}
```

## 🔍 注意事项

### 1. 缓冲区管理
- 必须分配两个缓冲区（黑白 + 红色）
- 红色缓冲区可以为 NULL（此时只能显示黑色）
- 及时释放缓冲区，避免内存泄漏

### 2. 显示刷新
- 绘图操作后必须调用 `epd_display(buffer_bw, buffer_red)` 刷新
- 两个缓冲区会同时发送到显示屏

### 3. 颜色选择
- `EPD_COLOR_BLACK`：用于主要内容、文字、边框
- `EPD_COLOR_RED`：用于强调、警告、高亮
- `EPD_COLOR_WHITE`：用于清屏、擦除

### 4. 坐标系统
- 使用用户坐标：X[0-295], Y[0-151]
- 内部自动转换为 SSD1680 内部坐标
